# App TDAH 🌱

App personal para organizarme con TDAH: calendario, pendientes con fechas límite y colores, rutinas con temporizador, hábitos, metas y un estante de libros. Estilo minimalista tipo bullet journal, pero sin tener que dibujar nada.

- PWA (se instala desde el navegador en iPhone y Android)
- 100% gratis: GitHub Pages + Supabase (plan gratis)
